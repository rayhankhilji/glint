# Eval datasets

Landmark-only `saccade-trace/v1` JSONL recordings (ARCHITECTURE §10.6), stored with Git LFS. Images or video must never appear here (G-SEC-01, G-SEC-13).

- `ci/`: small set (≤ 20 MB) used by the CI eval gate.
- `v1/`: the full, subgroup-tagged release set.

Recording protocol and consent requirements: TESTING_GUIDE §4.2. Consent forms are stored offline, never in this repository.
